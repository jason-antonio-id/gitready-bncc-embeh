# [Embeh]

Project kolaboratif tim BNCC untuk study case GitReady 2.0 — membangun landing page menggunakan Git & GitHub workflow (branching, Pull Request, code review).

![Screenshot](screenshot.png)

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Fitur Utama

- Navigasi switch antar profil anggota (Anggota 1, 2, 3) via tombol navbar
- Like counter interaktif dengan tombol 👍
- Dark mode toggle
- Menampilkan info profil (foto, nama, role, deskripsi, skill list) untuk tiap anggota
